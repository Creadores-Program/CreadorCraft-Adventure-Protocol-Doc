# SetInventory Datapacket
Este datapacket lo envía el servidor, se envia para establecer el inventario del jugador por ids de items

| **Packet ID** | **Nombre** | **Tipo** | **Ejemplo** | **Notas** |
| :--- | :--- | :--- | :--- | :--- |
| 0x0D | Ítems | unsigned short[25] | unsigned short[...] | Ítems del inventario
