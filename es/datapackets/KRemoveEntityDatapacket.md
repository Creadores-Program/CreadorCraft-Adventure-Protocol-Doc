# RemoveEntity Datapacket
Este datapacket lo envía el servidor, se usa para eliminar una entidad en el mundo que no sea el jugador por ID mundial.

| **Packet ID** | **Nombre** | **Tipo** | **Ejemplo** | **Notas** |
| :--- | :--- | :--- | :--- | :--- |
| 0x14 | ID Mundial | unsigned short | 5 | Id unico de la entidad que diferencia de las demas en el mundo |
