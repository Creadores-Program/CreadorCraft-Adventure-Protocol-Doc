# SetGravity Datapacket
Este datapacket lo envía el servidor, se usa si quieres que el cliente prediga la gravedad o no, si al jugador le quitas la gravedad podrá volar en el mundo.

| **Packet ID** | **Nombre** | **Tipo** | **Ejemplo** | **Notas** |
| :--- | :--- | :--- | :--- | :--- |
| 0x1B | Gravedad | boolean | true | activa o desactiva la gravedad |
